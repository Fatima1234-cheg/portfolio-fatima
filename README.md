## Fonctionnalités

### Design et expérience utilisateur

| Fonctionnalité | Description |
|---|---|
 | Thème sombre | Design moderne et cohérent |
|Curseur personnalisé | Effets de survol interactifs |
 |Défilement fluide | Smooth scrolling avec Lenis |
|Responsive | Adapté mobile, tablette et desktop |
 |Multilingue | Français et anglais |

### Animations

- Animations au scroll avec **GSAP ScrollTrigger**
- Effet **typewriter** dans la section d'accueil
- Micro-interactions sur les éléments interactifs
- Transitions fluides entre les sections

## Démarrage rapide

**Prérequis :** Node.js 18+ et npm.

```bash
# Cloner le dépôt
git clone https://github.com/fatima1234-cheg/portfolio-fatima.git
cd portfolio-fatima

# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Générer le build de production
npm run build
```

```text

│   ├── components/

│   ├── App.vue              # Composant racine

```

## Personnalisation

### Couleurs

Les variables sont définies dans `src/styles/_variables.scss` :

| Variable | Valeur | Usage |
|----------|--------|-------|
| `--primary` | `#6366f1` | Couleur principale (indigo) |
| `--accent-pink` | `#f472b6` | Accent rose |
| `--accent-cyan` | `#22d3ee` | Accent cyan |
| `--bg-primary` | `#0a0a0f` | Fond sombre |

### Contenu

Le contenu est centralisé dans le store Pinia `src/stores/portfolio.ts` : projets, expériences, compétences et certifications.
